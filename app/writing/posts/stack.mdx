This is what I use to build web apps. Tools change; the criteria do not: fast development, reliability, performance, and simplicity.

## Frameworks

### [Next.js](https://nextjs.org/)

My default for full-stack React apps. Server Components cut client-side JavaScript, simplify data fetching, and let me use backend resources without an extra API layer.

### [Angular](https://angular.dev/)

A good fit when a large, distributed team needs strict structure. The opinionated layout, built-in dependency injection, and full tooling keep everyone consistent from day one.

### [Astro](https://astro.build/)

For content sites, docs, and marketing pages where speed matters most. Zero JavaScript by default, with content collections that make Markdown and MDX painless.

## Backend and APIs

### [Node.js & Express](https://expressjs.com/)

My choice for small, flexible REST APIs in JavaScript. It stays out of the way and keeps middleware simple.

### [.NET & ASP.NET Core](https://learn.microsoft.com/en-us/aspnet/core/)

For services that need enterprise throughput and strict typing. Strong runtime performance, native dependency injection, and async handling that holds up under load.

## Styling and Design

### [Tailwind CSS](https://tailwindcss.com/)

Styles live next to the markup, so I stop switching files. The compiler keeps the final CSS bundle small and predictable.

### [shadcn/ui](https://ui.shadcn.com/)

Accessible components built on Radix UI. The code sits in your repo instead of `node_modules`, so you own the styling and behavior.

### [Motion](https://motion.dev/)

Small interactions and smooth layout changes make an interface feel alive. The declarative API stays fast.

## AI

### Hermes and GLM 5.3 Flash

Part of my daily workflow for coding, debugging, and ideas. Fast and low-latency enough to work as a pair programmer — good at breaking down functions, drafting types, and answering design questions.

## Hosting

### Vercel

Where my Next.js apps go by default. Preview deployments, edge routing, and CI/CD with almost no setup.

### AWS

When a project needs finer control:

- **CloudFront** — low-latency delivery and edge caching worldwide.
- **S3** — durable object storage for uploads and media.
- **EC2** — dedicated servers for custom daemons or specific workloads.

## Community

Outside of code, I run IT workshops and volunteer with programs that teach beginners and underprivileged students. Explaining a concept is the fastest way to learn it properly.

Pick tools that solve the real problem, stay maintainable, and let you focus on shipping value.
